# CodeAlpha Task 3 — Minecraft-Inspired Portfolio

An advanced, responsive portfolio website built with pure HTML, CSS and JavaScript.

## Features
- Minecraft-inspired pixel/block visual language
- Animated clouds and floating blocks
- Pixel-style loading screen
- Responsive mobile navigation
- Scroll reveal animations
- Active navigation section highlighting
- Interactive background pixel burst
- Skills progress bars
- Experience timeline
- Projects and education sections
- Contact section with email and phone links
- No framework or build step required

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` with Live Server, or open the file directly in a browser.
3. No Node.js/npm installation is required.

## Deployment
This is a static site and can be deployed to GitHub Pages or Netlify.

Personal details and experience are based on the provided resume.
